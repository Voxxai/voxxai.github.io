# Voxxai visual system

## Thesis

A late-night developer zine filtered through Jinx energy—not a cyberpunk dashboard and not a generic SaaS landing page.

## Rules

- Use one cool-black neutral system with blue, pink and acid-lime accents.
- Let typography, spacing and hard dividers create hierarchy.
- Keep corners square or nearly square; avoid pill UI unless the shape communicates state.
- Use the Jinx portrait once, as identity rather than decoration.
- Write concrete copy in Gilian's voice. No claims such as “innovative,” “delightful,” “world-class” or “passionate developer.”
- Projects must have a public, unauthenticated source URL before appearing as public work.
- Prefer editorial rows and asymmetric composition over repeated icon-card grids.
- Motion is user-triggered feedback, lasts roughly 100–220 ms and respects reduced-motion preferences.

## Never add

- purple-to-cyan glow blobs;
- glassmorphism panels;
- generic three-card feature rows;
- fake terminal windows;
- decorative dashboards or made-up metrics;
- auto-playing entrance animations;
- stock imagery or generated UI screenshots;
- multiple competing call-to-action styles.
